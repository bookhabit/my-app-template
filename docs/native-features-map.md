## 1. 센서 & 모션

패키지: `expo-sensors`

---

### 1-1. Accelerometer (가속도계)

**감지**: X/Y/Z 3축 속도 변화, 충격, 흔들기

| 항목 | 내용 |
|------|------|
| **서비스명** | 🍾 **탄산 폭발 룰렛** |
| **한 줄 설명** | 폰을 흔들면 흔들수록 위험 게이지가 올라가는 복불복 게임 |
| **게임 방식** | 순서대로 돌아가며 폰을 흔든다 → 누적 진동량이 임계값 넘으면 "폭발" 판정 → 벌칙 |
| **바이럴 포인트** | 손에 땀 쥐는 순간을 15초 숏폼으로 공유 |
| **구현 핵심** | `Accelerometer.addListener`로 magnitude 계산 → 누적합 → 임계값 비교 |
| **공유 방식** | 폭발 순간 화면 스크린샷 + 결과 카드 자동 생성 |

```ts
// 핵심 로직 스케치
const magnitude = Math.sqrt(x**2 + y**2 + z**2) - 1; // 중력 제거
cumulativeShake += magnitude * deltaTime;
if (cumulativeShake > THRESHOLD) triggerExplosion();
```

### 1-2. Gyroscope (자이로스코프)

**감지**: 회전 각속도 (기울기 방향, 회전 속도)

| 항목 | 내용 |
|------|------|
| **서비스명** | 🎭 **이마 위에서 맞춰봐** |
| **한 줄 설명** | 폰을 이마에 대고 기울여서 카테고리 맞추기 (Heads Up 클론) |
| **게임 방식** | 이마에 폰 → 단어 표시 → 맞추면 위로 기울이기(다음) / 모르면 아래로(패스) |
| **바이럴 포인트** | 황당한 표정으로 단어 설명하는 장면이 자동으로 숏폼 소재 |
| **구현 핵심** | `Gyroscope`로 pitch값 감지 → +임계값 이상 = 정답 / -임계값 이하 = 패스 |
| **공유 방식** | 라운드 결과 카드 (정답수 / 총 시간 / 최고 연속 정답) |

### 1-3. Magnetometer (자력계 / 나침반)

**감지**: 방위각 (N/S/E/W), 자기장 세기

| 항목 | 내용 |
|------|------|
| **서비스명** | 🧲 **자력 룰렛** |
| **한 줄 설명** | 폰을 빙글빙글 돌리다 멈추면 자석 바늘이 가리키는 사람이 벌칙 |
| **게임 방식** | 테이블 위에서 폰을 돌리면 실시간 나침반 바늘 표시 → 멈춘 방향이 가리키는 사람 |
| **바이럴 포인트** | 오프라인 룰렛을 폰 하나로 대체 → "우리 이제 룰렛 앱 삭제함" |
| **구현 핵심** | `Magnetometer`로 heading 계산 → 각도를 방향으로 변환 |

```ts
const heading = Math.atan2(y, x) * (180 / Math.PI);
```

### 1-4. Barometer (기압계)

**감지**: 기압, 상대 고도 변화

| 항목 | 내용 |
|------|------|
| **서비스명** | 📊 **누가 더 높이 들었나** |
| **한 줄 설명** | 폰을 위로 들거나 쌓아올려서 최고 높이 경쟁 |
| **게임 방식** | 같은 출발점에서 시작 → 30초 동안 최대한 높이 들기 → 고도 변화량으로 순위 |
| **바이럴 포인트** | 황당하게 폰 높이 드는 모습 + 고도 데이터 결과 카드 |
| **주의** | 기압 변화 → 고도 변화 분해능 약 0.1~0.5m 수준 (실내 충분) |

### 1-5. Pedometer (만보계)

**감지**: 걸음 수, 거리

| 항목 | 내용 |
|------|------|
| **서비스명** | 🏃 **30초 제자리 뛰기 배틀** |
| **한 줄 설명** | 30초 동안 제자리 뛰기 → 걸음수 많은 사람 승리 |
| **게임 방식** | 카운트다운 후 전원 동시 시작 → 실시간 걸음수 표시 → 결과 공유 |
| **바이럴 포인트** | 뛰는 모습 + "나 오늘 운동함" 밈 결과 카드 |
| **구현 핵심** | `Pedometer.watchStepCount`로 실시간 스텝 구독 |

### 1-6. DeviceMotion (통합 모션)

**감지**: 가속도 + 자이로 + 방향 통합값

| 항목 | 내용 |
|------|------|
| **서비스명** | ⚖️ **수평 유지 챌린지** |

| **게임 방식** | 화면에 물방울 표시 → 기울어지면 물 쏟아지는 애니메이션 → 가장 오래 버틴 사람 승리 |
| **바이럴 포인트** | 온몸으로 수평 유지하는 진지한 표정 = 자동 밈 |
| **구현 핵심** | `DeviceMotion`의 `rotation.beta`, `rotation.gamma`로 기울기 계산 |

| **게임 방식** | 전면 카메라로 표정 실시간 추적 → 입꼬리 올라감/눈 좁아짐 감지 시 "웃음 탐지!" → 벌칙 |
| **바이럴 포인트** | 억지로 무표정 유지하는 표정 + "AI가 내 웃음 잡음" 결과 |

### 3-1. Microphone dB (실시간 데시벨)

**감지**: 주변 소리 크기 (dB)

| 항목 | 내용 |
|------|------|
| **서비스명** | 🤫 **침묵 생존 게임** |

| 서비스명 | 기능 | 설명 |

| 📢 **비명 크기 배틀** | dB 최고치 측정 | 3초 동안 가장 크게 소리 지르기 경쟁 |
| 🎤 **노래방 볼륨 챌린지** | 특정 dB 유지 | 볼륨 게이지를 특정 구간에 3초 유지하기 |

## 5. TTS & STT 음성

### 5-1. TTS (Text-to-Speech)

**기능**: 텍스트를 음성으로 변환, 속도/피치 조절

| 항목 | 내용 |
|------|------|
| **서비스명** | 🎙️ **AI 게임 진행자** |
| **한 줄 설명** | 게임 진행을 음성으로 안내하는 AI 사회자 |

| **바이럴 포인트** | AI 목소리가 황당한 벌칙을 진지하게 읽어주는 것 자체가 웃김 |
| **구현 핵심** | `Speech.speak(text, { language: 'ko-KR', pitch: 1.2, rate: 0.9 })` |

### 5-2. STT (Speech-to-Text / 음성 인식)

**기능**: 음성을 텍스트로 변환, 실시간 인식

| **게임 방식** | 금지어 3개 설정 → 대화 중 음성 인식으로 실시간 감지 → 말하면 즉시 경보 + 벌칙 |
| **바이럴 포인트** | 방심하다 금지어 말하는 순간 경보 울리는 장면 |
| **구현 핵심** | `ExpoSpeechRecognitionModule.start()` + `result` 이벤트에서 금지어 포함 여부 체크 |

## 구현 우선순위 로드맵

```
Phase 1 — 설치 없이 즉시 테스트 가능 (현재 패키지로)
├── 햅틱 심장박동 카운트다운 (expo-haptics ✅)
├── 손가락 뽑기 (gesture-handler ✅)
└── 표정 타임캡슐 — 촬영만 (expo-camera 설치 필요)

Phase 2 — expo install만 하면 됨 (Expo Go 지원)
├── 탄산 폭발 룰렛 (expo-sensors)
├── 이마 위에서 맞춰봐 (expo-sensors)
├── 자력 룰렛 (expo-sensors)
├── 침묵 생존 게임 (expo-audio)
├── 비명 크기 배틀 (expo-audio)
├── 배터리 복불복 (expo-battery)
├── AI 게임 진행자 (expo-speech)
└── 금지어 탐지 게임 (expo-speech-recognition)

Phase 3 — EAS 개발 빌드 필요 (Expo Go 미지원)
├── 웃참 배틀 (vision-camera + face detector)
├── 기울기 미로 게임 (react-native-skia)
├── 블루투스 즉석 방 (react-native-ble-plx)
└── 코 대기 대결 (proximity sensor)
```
